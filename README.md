## Overview

FarZone is a third-person action-adventure PC game developed as the Final Year Project for the BS Software Engineering program. The project focuses on immersive gameplay, AI-driven enemies, combat mechanics, NPC interactions, and story progression while applying object-oriented programming and software engineering principles.
